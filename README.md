## Run it

```sh
node main.ts
```

This writes exactly one emoji to `/output/entry.txt` — a single glyph, nothing else. Entry for the [Your Agent in One Emoji](https://make.fun/bounty/u-boge-your-agent-in-one-emoji-db30c1e4) bounty on make.fun.

## Why 🔁

An AI agent is not a chatbot that answers once and stops. It works in a loop — plan, act, observe the result, adjust, and try again until the task is done. The loop is what makes it an agent, and 🔁 is that loop in one familiar shape: it reads instantly at small size, it says something specific about how the agent works, and it is not the obvious robot, brain, or smiley half the field will send.
